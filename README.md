# My Portfolio

A modern personal portfolio website built with HTML, CSS, and JavaScript to showcase projects, skills, and contact information.

## Overview

This portfolio website presents:
- A professional personal introduction
- About section with frontend development background
- Services offered
- Featured project cards with live demos
- Contact form for inquiries
- Responsive layout for desktop and mobile devices

## Live Demo

Visit the portfolio here:
- https://madhubala46.github.io/My-Portfolio/

## Features

- Responsive single-page layout
- Smooth scrolling navigation
- Animated typing effect for role text
- Social media links for GitHub and LinkedIn
- Project showcase cards with external links
- Contact form using EmailJS
- Mobile-friendly navigation menu
- Clean, modern UI design

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Typed.js
- ScrollReveal
- EmailJS

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/Madhubala46/My-Portfolio.git
```

2. Open the project folder:

```bash
cd My-Portfolio
```

3. Open `index.html` in your browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
